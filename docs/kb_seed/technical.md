# Technical Setup — Women in Tech Community Platform

## Getting Started
1. Sign up at the community portal with your email.
2. Verify your email (check spam if not received in 10 minutes).
3. Join the Telegram group via the invite link sent post-verification.
4. Complete your profile (track: beginner/mid/senior) to get matched.

## Common Errors

**"Invite link expired"**
Telegram invite links expire after 48 hours for security. Request a fresh
link from @community_admin.

**"Can't log into the resource hub (Notion)"**
The Notion workspace requires you to accept the invite using the *same email*
you registered with. Using a different email will show "access denied."

**"Zoom link not working for group sessions"**
Group session links rotate weekly and are posted in Telegram 1 hour before
each session — old bookmarked links will not work.

## Supported Platforms
Telegram (community chat), Notion (resource hub), Zoom (live sessions). No
mobile app currently — everything is accessible via browser/Telegram app.
